Navigation Guide

Use the screen tabs above or select a box inside the flow map. The main student journey is: Student Home → Daily Check-in → Save Entry → Monthly Summary. Selecting a low mood opens support choices. Staff members see class-level summaries, while an authorised social worker reviews alerts triggered by seven consecutive low-mood entries.
